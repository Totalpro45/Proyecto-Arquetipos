# Proyecto-Arquetipos

En el compendio de la asignatura se trabajan nueve patrones de trama para estructurar historias con datos. Para este trabajo elegí cinco arquetipos diferentes que no aparecen en esa lista, tomados de dos referencias que sí están en la bibliografía del curso: cuatro vienen de los 20 Master Plots de Ronald Tobias (el enigma, la rivalidad, el sacrificio y la metamorfosis) y uno de los arcos geométricos de Reagan et al. (el arco de Edipo).
